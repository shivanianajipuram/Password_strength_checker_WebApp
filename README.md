# PasswordStrengthChecker

A password security and validation web application that checks the strength of user passwords based on different security rules. The application provides real-time feedback and displays whether the password is weak, medium, or strong using an interactive and user-friendly interface.

The project helps users create secure passwords and demonstrates the implementation of frontend validation, cybersecurity fundamentals, and dynamic UI updates in a web application environment.

---

## Features Included

- Password Length Validation
- Uppercase and Lowercase Detection
- Number Validation
- Special Character Detection
- Common Password Detection
- Real-Time Strength Meter
- Live Password Suggestions
- Show/Hide Password Option
- Responsive UI Design
